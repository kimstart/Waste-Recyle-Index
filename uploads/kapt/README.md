# K-APT 입찰결과 엑셀 올리는 곳

1. K-APT(www.k-apt.go.kr) → 입찰정보 → **사업비 비교검색** (PC 화면에서)
2. **주요 사업별 가격비교** 탭에서 키워드 **재활용품**을 누르거나, 입찰공고명에 `재활용` 입력
3. 지역 서울·인천·경기, **검색기간은 1개월 이내** (K-APT 제한: 엑셀은 1개월 단위로만 받아짐)
4. 결과 목록 위 정렬(최신순·저가순·고가순) 오른쪽의 **EXCEL** 버튼 → 파일 저장
5. 이 폴더에서 *Add file → Upload files* 로 올리고 *Commit changes* (여러 달 파일을 한꺼번에 올려도 됨)

올리면 자동으로 읽어 폐플라스틱 페이지 '아파트 단지 재활용품 매각·수거'에 낙찰금액·낙찰업체·세대수를 반영하고,
원본 엑셀은 저장소에서 지웁니다(결과 값만 data/apt_sales.json 에 남음).
