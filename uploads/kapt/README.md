# K-APT 입찰결과 엑셀 올리는 곳

1. K-APT(www.k-apt.go.kr) → 입찰정보 → **입찰결과**
2. 검색 조건: 입찰공고명 `재활용`, 지역 서울·인천·경기, 기간(처음 1년, 이후 1개월)
3. **엑셀 다운로드** → 이 폴더에서 *Add file → Upload files* 로 올리고 *Commit changes*

올리면 자동으로 읽어 폐플라스틱 페이지 '아파트 단지 재활용품 매각·수거'에 낙찰금액·낙찰업체·세대수를 반영하고,
원본 엑셀은 저장소에서 지웁니다(결과 값만 data/apt_sales.json 에 남음).
